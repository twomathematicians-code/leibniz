Input — Theorem & Proof

📋 Theorem T + Proof π
Uploaded as JSONL / PDF, or typed manually
enters the pipeline

Three Independent Gates

🔐 Gate 1 · Validity
Lean 4 type‑check (exit 0)
or encyclopedia pattern‑match
●  Certified  |  ◐  Skipped  |  ○  Rejected
🧭 Gate 2 · Alignment
Concept overlap score vs. encyclopedia
Token match + known‑good proof boost
Score ∈ [0.00, 1.00]  →  matched / missing concepts
📖 Gate 3 · Reading
Three graded tiers of human‑style scrutiny
Graded tiers
Easy
Surface syntax · typos · well‑formedness
→
Medium
Logic flow · tactic pre‑conditions
→
Hard
Deep correctness · edge cases · faithfulness
per‑tier verdict → overall: PASS · WARN · FAIL
all three must clear
◈  Final Verdict
PASS  ·  proof clears all gates  ·  certificate issued
or
ATTENTION  ·  one or more gates flagged issues  ·  review required

Input — Seed Topic

🔍 Seed Topic
e.g. "linear algebra", "prime numbers", "set theory"
encyclopedia lookup

Three Stages

1 · Discover
Propose n conjectures matching the seed
keyword retrieval → encyclopedia entries
informal + Lean statements + rationale
2 · Prove
Generate k candidate tactic blocks per conjecture
shape‑based templates: rfl / simp / ring / aesop
or LLM sampling (HF / remote backend)
k candidate proof strings
3 · Verify
Compile each candidate in Lean 4
first passing proof → certified
none pass → conjecture is unproven
certified theorems + unproven conjectures
output
◈  Discovery Result
Certified: m theorems  |  Unproven: n − m conjectures
